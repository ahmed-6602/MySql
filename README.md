# MySql
MySQL SQL Practice

A hands-on MySQL practice repository focused on learning and improving SQL through simple, real-world database scenarios.

This repository currently starts with a Student Management database containing students, subjects, marks, fees, and attendance. The exercises are designed to practice SQL concepts such as:

Database and table creation
CREATE TABLE and INSERT
SELECT queries
INNER JOIN
LEFT JOIN
RIGHT JOIN
FULL OUTER JOIN concepts
Filtering with WHERE
Sorting with ORDER BY
Aggregations such as COUNT, SUM, AVG, MIN, and MAX
GROUP BY and HAVING
Subqueries
CASE statements
Multiple-table joins
Primary keys and relationships
Finding missing or unmatched records

The repository will continue to grow with more MySQL query exercises and different datasets as I practice and learn.

Goal: Build strong SQL fundamentals through consistent hands-on practice and gradually move from basic queries to more advanced SQL problems.
